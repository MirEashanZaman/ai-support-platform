# Dashboard (`/dashboard`)

Next.js Admin & Support Agent Dashboard for the AI Support Platform:
- **Owner View:** Document uploads (`PDF`, `MD`, `TXT`, `URL`), widget configuration, team role invitations (`Owner`, `Agent`, `Viewer`), and analytics/unanswered questions.
- **Agent View:** Real-time escalated chat inbox powered by Socket.io WebSockets, conversation claiming, and live customer replies.
- **Viewer View:** Read-only access to chat transcripts and analytics.
