# AI Evaluation Suite (`/evals`)

Automated evaluation runner and benchmark datasets (50+ test questions per sample business, including **Oil Supply** and a second demo tenant):
- **Categories:** Answerable, Partially Answerable, Unanswerable (should escalate), and Prompt-Injection attempts.
- **Metrics:** Answer accuracy (target ≥ 85%), Hallucination rate (target < 5%), and Unanswerable escalation rate (target ≥ 90%).
